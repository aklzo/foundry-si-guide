権限の境界

アカウント
モデルのデプロイ・API キー・ネットワーク
プロジェクト
エージェント・ファイル・接続・評価
エージェント
「呼ぶ」権限(Agent Consumer)だけを絞れる
API キーはエージェント単位の権限を迂回する実測
エンドポイント・ファイル・メモリまでキーで通る。disableLocalAuth で止める(約 1 分で効き、拒否は 403)

プロジェクトの中で分けられないもの

応答の続き実測
他人の応答 ID を previous_response_id に入れると、続きの回答で中身が読める
メモリ実測
プロジェクトの経路では x-memory-user-id で他人の記憶が読める(エージェントのエンドポイントでは無視される)
接続のシークレット実測
プロジェクトに付けた Foundry User で読める
ファイル実測
他人のファイル ID を添付に指定しても受理される(内容が渡るかは未確認)
Code Interpreter のコンテナー
同じプロジェクトで共有(公式)
他人の hosted セッション
Foundry User は一覧できる(公式)
ナレッジベースの権限絞り込み ユーザーのトークンがないとき、絞らずに返すと書くページと返さないと書くページがある(公式)
分かれていたもの実測 会話と応答の取得は呼び出し元ごとに分かれる(他人の ID では 404)
