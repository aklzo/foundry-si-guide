## ハイライト(SI 選定観点の要点)

- **新ポータルは GA、ただし機能単位で GA / プレビューが混在。** [Feature readiness at GA](https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability) の表(ms.date 2026-08-14 のまま 2026-09-23 に更新され **Routines が Preview → GA**)が唯一の体系的な一覧。**2026-11-17 の更新で Operate が Manage に統合**(Fleet / Cost / Operations / Compliance = Preview、Quota・プロジェクト詳細 = GA。ポータルは 5 セクション)され、**managed compute の Preview 注記が消え(2026-11-20 GA)、Tracing は外部エージェントでも GA** になった。Monitoring・Workflows・Memory・AI Gateway・Agents — Voice Live・Agent optimizer(Limited preview)等はプレビュー継続(Ignite のブログで GA と発表されたものとの両論は上の「注意」)。
- **Agent Service はサービスとして GA**(Responses API ベースの v2)。hosted agents の初期プレビュー基盤は 2026-08-20 でサポート終了済(未移行なら再デプロイ)、ビジュアル Workflows は**プレビューのまま 2026-12-01 廃止**で Microsoft Agent Framework へ誘導。一方 2026-08 には **Autopilot(Agent 365 連携、hosted 専用。ステータス要確認)・長時間実行 hosted agents(preview)・Skills / private skill catalog(preview)・Agent optimizer の prompt agent 対応(ポータル、preview)**が追加され、「GA だが足元が動いている」状態は継続。**2026-09 には GA 化の第 2 波**: Routines(GA 一覧表+公式ブログ 2026-09-24。利用不可は UK West / Switzerland West / **Japan West** / UAE North / Norway East の 5 リージョンのみに拡大)・A2A(v1.0 の `a2a` 型。v0.3 / `a2a_preview` はプレビュー)・Tool search(Azure ブログ 2026-09-24 は GA、Learn は preview 表記のまま)。同時に **Voice agents(`kind: voice`)・hosted agent の network egress controls・Foundry insights** がプレビューで追加され、Autopilot は公式ブログ(2026-06-03)で public preview と判明(Learn はラベルなし)。2026-09-28 には **hosted agent のユーザー委任アクセス(アプリ管理の OBO+`x-client-*` ヘッダー転送)**の公式手順と M365 公開のトラブルシューティングページが追加された(詳細は [03](./03-agent-service.md))。
- **ハブベースプロジェクト(classic)は廃止日未発表のレガシー扱い。** 新規投資は Foundry プロジェクトに集中と明言。classic にしか残っていないのは **prompt flow(2027-04-20 廃止予定)**・serverless API デプロイ・Language の CLU / CQA / カスタム NER・Content Understanding のカスタム作成等(PII・言語検出・TA4H・CU の一部 prebuilt は新ポータルにプレイグラウンドあり)で、**マネージドコンピュートは新ポータルに対応済み**(2026-11-20 に GA。Data Zone は US / EU のみで APAC なし)。
- **CLI は一級市民ではない(2026-11 からは azd が主役)。** 専用の `az foundry` は存在せず、リソース管理は `az cognitiveservices`(GA。CMK・NSP・Managed VNet は CLI 手順あり。**`az cognitiveservices agent` は Deprecated で 2027-02-28 後の最初のリリースで削除**)、エージェント開発・評価は azd 拡張(**2026-11-05 に `microsoft.foundry` 1.0 ほか主要拡張が GA、azd 1.37.0 以上**。evaluations / dataset 拡張は Beta のまま)、それ以外の多くの機能は「ポータル + SDK/REST のみ」でドキュメントに CLI 手順がない。2026-08 以降は**コーディングエージェント経路(Foundry Skill / Foundry MCP Server〈preview、79 ツール〉/ Foundry Canvas〈preview〉/ DevPack)**が公式手段として整備されつつある。**Foundry Dev Pack は 2026-09-15 に正式発表**(`winget install Microsoft.FoundryDevPack` 等のワンコマンドで az / azd / Foundry 拡張 / Skill / VS Code 拡張 / Canvas を一括導入。7・8 月号時点の版は 0.1.3 preview)。**Dev Pack は 2026-11-18 に GA**(0.1.6)、Foundry MCP Server・Canvas は preview のまま。
