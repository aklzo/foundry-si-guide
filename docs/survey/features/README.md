- **正(マスター)は Markdown**(生成 AI 用)。人間用 HTML は共有ビルダー `docs/survey/tools/md2html.py` で `html/` 配下に自動生成します。HTML を直接編集しないでください。

## ステータス凡例

| 表記 | 意味 |
| --- | --- |
| GA | 一般提供(General Availability)。SLA・サポート対象 |
| パブリックプレビュー | 公開プレビュー。SLA なし・仕様変更あり得る。本番利用は原則非推奨 |
| 限定プレビュー | 申請制・招待制のプレビュー(limited access / gated) |

## ハイライト(SI 選定観点の要点)

- **新ポータルは GA、ただし機能単位で GA / プレビューが混在。** [Feature readiness at GA](https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability) の表(ms.date 2026-08-14 のまま 2026-09-23 に更新され **Routines が Preview → GA**)が唯一の体系的な一覧。Operate(コントロールプレーン)の大半・Monitoring・Workflows・Memory・AI Gateway 等はプレビュー継続。Quota・プロジェクト詳細は新設の **Manage** セクション(GA)に移った。
- **Agent Service はサービスとして GA**(Responses API ベースの v2)。hosted agents の初期プレビュー基盤は 2026-08-20 でサポート終了済(未移行なら再デプロイ)、ビジュアル Workflows は**プレビューのまま 2026-12-01 廃止**で Microsoft Agent Framework へ誘導。一方 2026-08 には **Autopilot(Agent 365 連携、hosted 専用。ステータス要確認)・長時間実行 hosted agents(preview)・Skills / private skill catalog(preview)・Agent optimizer の prompt agent 対応(ポータル、preview)**が追加され、「GA だが足元が動いている」状態は継続。**2026-09 には GA 化の第 2 波**: Routines(GA 一覧表+公式ブログ 2026-09-24。利用不可は UK West / Switzerland West / **Japan West** / UAE North / Norway East の 5 リージョンのみに拡大)・A2A(v1.0 の `a2a` 型。v0.3 / `a2a_preview` はプレビュー)・Tool search(Azure ブログ 2026-09-24 は GA、Learn は preview 表記のまま)。同時に **Voice agents(`kind: voice`)・hosted agent の network egress controls・Foundry insights** がプレビューで追加され、Autopilot は公式ブログ(2026-06-03)で public preview と判明(Learn はラベルなし)。2026-09-28 には **hosted agent のユーザー委任アクセス(アプリ管理の OBO+`x-client-*` ヘッダー転送)**の公式手順と M365 公開のトラブルシューティングページが追加された(詳細は [03](./03-agent-service.md))。
- **ハブベースプロジェクト(classic)は廃止日未発表のレガシー扱い。** 新規投資は Foundry プロジェクトに集中と明言。classic にしか残っていないのは **prompt flow(2027-04-20 廃止予定)**・serverless API デプロイ・Language の CLU / CQA / カスタム NER・Content Understanding のカスタム作成等(PII・言語検出・TA4H・CU の一部 prebuilt は新ポータルにプレイグラウンドあり)で、**マネージドコンピュートは新ポータルに対応済み**(パブリックプレビュー)。
- **CLI は一級市民ではない。** 専用の `az foundry` は存在せず、リソース管理は `az cognitiveservices`(GA。CMK・NSP・Managed VNet は CLI 手順あり)、エージェント開発・評価は azd 拡張(レジストリ表記は Beta)、それ以外の多くの機能は「ポータル + SDK/REST のみ」でドキュメントに CLI 手順がない。2026-08 以降は**コーディングエージェント経路(Foundry Skill / Foundry MCP Server〈preview、79 ツール〉/ Foundry Canvas〈preview〉/ DevPack)**が公式手段として整備されつつある。**Foundry Dev Pack は 2026-09-15 に正式発表**(`winget install Microsoft.FoundryDevPack` 等のワンコマンドで az / azd / Foundry 拡張 / Skill / VS Code 拡張 / Canvas を一括導入。7・8 月号時点の版は 0.1.3 preview)。
- **Claude(Anthropic)が 2026 年に本格参入。** 「Hosted on Azure」形態の claude-opus-5 / sonnet-5 / opus-4-8 等は GA + Data Zone (US) 対応(Fable 5.1 / Mythos 5.1 は Preview)。2026-08-17 に Structured outputs / Web search / Web fetch / Tool search / MCP connector(Beta)も Hosted on Azure で利用可に。**2026-09-22 に `claude-opus-5-5`、2026-09-28 に `claude-sonnet-5-5`、2026-10-08 に `claude-haiku-5-5` が追加**(いずれも GA、US Data Zone 対応。haiku-5-5 は 1M context・effort 対応の初の Haiku で APAC リージョンなし。sonnet-5-5 / haiku-5-5 の Hosted on Azure × Global Standard はリージョン表に行がなく要確認)。ただし Anthropic SDK + Marketplace 課金 + Foundry 組み込みコンテンツフィルター非適用という独自制約は継続。
- **GPT-6 系: Astra(`gpt-6-astra`)が 2026-09-03 に GA、Sol / Luna(`gpt-6-sol` / `gpt-6-luna`)が 2026-09-22 に GA。** Astra の当初制約(tool calling は Responses API 必須、temperature 等非対応)は **2026-09-11 のドキュメント更新で撤廃**。EU Data Zone は **Sol / Luna は対応**、Astra は region 表が US のみ・2026-09-22 ブログは EU 対応と記載で**要確認**。3 モデルとも Regional・Batch なし。EU データ境界が要件の案件は Sol / Luna か gpt-5.6 系(2028-01-11 まで)で設計する。リタイア日はリタイア表 2026-09-21 版に未掲載。**2026-09-01 以降ローンチのモデルは Data Zone / Regional に価格プレミアムが掛かる**(詳細は [02](./02-models.md))。
- **2026-10-06 差分(09-29 以降)の要点:** **`gpt-6.1-sol`(09-29 GA)が GPT-6 世代で初めて APAC Data Zone(Japan East 含む)に対応**し、日本のデータ所在要件で GPT-6 世代を選べるようになった。**PTU は GPT-6 系が normalized token 会計でキャッシュ入力も容量を消費**(「キャッシュは 100% 控除」は旧規則)。リタイア表 09-28 版で **Claude 4.5 世代が 10-19 → 11-15 / 11-24 / 11-30**。hosted agent は**本番リリース手順(本番の版をピン留め → 候補版を版固定セッションで試験 → 昇格)と Terraform 対応(`azd ai agent init --infra=terraform` / AzAPI の data plane resource で版管理)**が公式化し、**ユーザー委任は toolbox 経由(`FoundryToolbox` が `x-agent-foundry-call-id` を転送)が公式推奨**に。閉域 FW では **Agent 365 観測エクスポート(`agent365.svc.cloud.microsoft`、`a365LoggingEnabled` は Agent 365 有効テナントで既定 true)**を許可するか無効化する。観測では**トレースの機微コンテンツを専用テーブル `AppGenAIContent` に隔離する仕組み(preview、移行日 2026-09-30)を見落としていたため追加**(ただし実測は二重書き)、合成評価器(preview)と評価の権限ページが新設。`azure-ai-projects` 2.8.0 は Agent Optimization / data generation / evaluator lifecycle を GA と書くが Learn・GA 一覧表は preview のまま、しかも **MAF(`agent-framework-foundry` 1.14.0)は `azure-ai-projects<2.8.0`**。Voice Live は **Japan East で azure-realtime / gpt-realtime-2.1 系が Global standard 可**に(従来記載を訂正)。**Anomaly Detector は 10-01 にサービス終了**。**同日のラボ実測では、hosted agent の休止明けにどの版が答えるかが構成で割れ(公式は「作成時の版」)、トレース本文は全経路で従来テーブルとの二重書き、`azure-monitor-opentelemetry` の既定サンプラーでトレースが歯抜けになった** — いずれも公式の記述だけで設計せず受入試験に入れる(詳細は 03 / 05)。
- **2026-10-14 差分(10-06 以降)の要点:** **期限** — **gpt-4.1-nano のリタイアは 2026-10-14 → 2027-04-14 に戻った**(3 度目の往復。リタイア表は en-us のページ日付が変わらないまま include だけが変わるので、日付の有無ではなく本文で確認する)。**On Your Data は本日 2026-10-14 が廃止日**。Fireworks の一部 Pay-per-token(2026-09-25)のように**リタイア表に載らない期限**があり、**Grok 4.7 以降の GA モデルは「最低 6 か月提供」**の新条項。**モデル** — Claude Haiku 5.5 GA(APAC なし)・**Grok 4.7 GA(Japan East / West の Global Standard 可)**・Microsoft-Decision-1(US / EU のみ、ステータス両論)。Flex processing(preview)の対象が 1 → 7 モデルに拡大。**Model router の既定プールに Fireworks 3 モデル(Microsoft 施設外・US のみで推論)が入った**ので、データ所在要件のある案件はモデルサブセットで絞る。ファインチューニングは概要ページ新設+プレビュー OSS・managed compute への LoRA 配置・interactive training(いずれも preview)。**ステータス表記の割れが拡大** — GA 一覧表は 2026-09-23 のまま不変だが、Learn の機能ページから「(preview)」が外れたもの(Agent optimizer・Rubric・traces→dataset・合成データセット・会話評価・会話シミュレーション)と、本文で GA と表明したもの(Browser Automation。閉域は非対応のまま)が出た。本書は GA 一覧表を正としてプレビュー扱いを維持。**Agent Service** — hosted のユーザー別セッション分離ページの改訂は文書整理で新機能ではない(委任利用者どうしはプラットフォームが隔てない・Foundry User は全利用者のセッションを管理できる)。idle timeout 上限は REST 仕様・azd 240 分 / Learn 60 分の両論。**capability settings の設定ページが 301 で消えた**(取り下げか移設か要確認)。M365 公開は受信経路(公衆インターネット経由・送信元 IP 照合)と、Copilot ライセンスのない利用者の従量課金が明記。**観測・安全** — **既定ストリーミングでも応答末尾 15〜30 語がガードレール適用前に届きうる**(content-streaming)。`azure-ai-agentserver-responses` 2.3.0 でテレメトリ送出が background 既定(要求完了時の到達が保証されない)。**Voice Live は Japan East でも HD voices・MAI-Transcribe が Global 処理**(リソースのリージョン外で処理されうると公式明記)。**開発** — azd の Foundry 拡張 3 本が camelCase 化の BREAKING、MAF Python 1.21 / `agent-framework-foundry` 1.14.1 は引き続き `azure-ai-projects<2.8.0`。詳細は各カテゴリと更新履歴。
