## 概要

Foundry リソース・プロジェクトのモデル、新旧ポータルの関係、ガバナンス(Manage。旧コントロールプレーン)、RBAC・ネットワーク・暗号化・ポリシー・コスト管理などのガバナンス機能を扱う。**新 Microsoft Foundry ポータルは GA 宣言済み**(「The new Microsoft Foundry portal is generally available (GA).」)だが、GA はコアシナリオ範囲であり、Manage の Fleet / Cost / Operations / Compliance・AI Gateway など一部機能はプレビュー継続である(本文「Several Build and Manage capabilities remain in preview」。出典: https://learn.microsoft.com/en-us/azure/foundry/concepts/general-availability 、updated_at 2026-11-17 版。2026-09-23 版までの「Operate」セクションは Manage に統合された)。**Microsoft IQ(2026-11-17 GA)は新しい SKU・サブスクリプションを伴わない位置づけ**で(「built on products customers already use, with no new SKU or subscription」— Ignite 2026 Book of News)、Foundry 側のリソースモデル・課金単位は変わらない(Foundry IQ は Microsoft IQ の構成要素。詳細は [04](./04-tools-knowledge.md))。

## 補足ノート(SI 判断に効く要点)

- **リソースモデルは連続性重視**: 改称・新ポータル化されても ARM 上は `Microsoft.CognitiveServices/accounts` のままで、既存の Azure Policy / RBAC / ネットワーク構成資産がそのまま効く。AOAI からのアップグレードは kind 変更のパッチ操作(非破壊)で、ロールバック手段も提供。
- **ハブベースの終息は「投資停止」段階**: 廃止日は未発表だが、新規投資は Foundry プロジェクトに集中と明言され、classic ドキュメントは NOINDEX・更新周期 365 日。classic 側にしか無いのは **prompt flow(2027-04-20 廃止予定)**・serverless API デプロイ・Azure Language 等で、**マネージドコンピュートは新ポータル側に移った**(2026-07 時点でパブリックプレビュー、**2026-11-20 に GA**)。「classic を残さないと機能が足りない」という論拠は年々弱くなっている。
