概要

Foundry Agent Service は Responses API を単一エントリポイントとするエージェント構築・実行のマネージドプラットフォーム。サービス本体は GA(「Foundry Agent Service is generally available (GA). Some sub-features are in public preview.」)。ただし旧世代(Agents v1 / Assistants API)の廃止と、Memory・Skills・voice-based agents・egress controls 等の新プレビュー機能の追加が同時進行しており(Routines は 2026-09 に GA 化。2026-09-26 確認)、「GA だが足元が動いている」状態である点に注意。2026-11-22 追記(Ignite 2026): voice agents(Learn・SDK・ブログは GA / GA 一覧表は Preview)・long-running hosted agents・hosted の network egress controls が GA 側に移った一方、Microsoft Copilot harness・memory snapshots・private CA trust・Azure Policy による egress 統制・session compute API・AgentBlueprint 認可などの新しいプレビューが加わり、状態は変わっていない。エージェントの作り方は prompt(既定ランタイム / Copilot harness を作成時に選択)・voice-based prompt・hosted の 3 種別と、エージェントを保存せず Responses API を直接呼ぶ ephemeral の計 4 通り(overview ms.date 2026-10-26・concepts/prompt-agents ms.date 2026-11-04)。
