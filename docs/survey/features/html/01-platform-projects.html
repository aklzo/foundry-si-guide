概要

Foundry リソース・プロジェクトのモデル、新旧ポータルの関係、ガバナンス(Manage。旧コントロールプレーン)、RBAC・ネットワーク・暗号化・ポリシー・コスト管理などのガバナンス機能を扱う。新 Microsoft Foundry ポータルは GA 宣言済み(「The new Microsoft Foundry portal is generally available (GA).」)だが、GA はコアシナリオ範囲であり、Manage の Fleet / Cost / Operations / Compliance・AI Gateway など一部機能はプレビュー継続である(本文「Several Build and Manage capabilities remain in preview」。出典: general-availability 、updated_at 2026-11-17 版。2026-09-23 版までの「Operate」セクションは Manage に統合された)。Microsoft IQ(2026-11-17 GA)は新しい SKU・サブスクリプションを伴わない位置づけで(「built on products customers already use, with no new SKU or subscription」— Ignite 2026 Book of News)、Foundry 側のリソースモデル・課金単位は変わらない(Foundry IQ は Microsoft IQ の構成要素。詳細は 04)。
