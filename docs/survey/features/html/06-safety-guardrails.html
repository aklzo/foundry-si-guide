概要(Ignite 2025 以降の再編)

旧「コンテンツフィルター」は「Guardrails and controls」枠組みに再編された。新ドキュメントは /azure/foundry/guardrails/ 配下(※パス自体の .../guardrails/ は 404。個別記事を参照する)。ガードレール=コントロールの名前付きコレクションで、各コントロールは「リスク × 介入ポイント × アクション」で定義される。

  • 介入ポイントは4つ: User input / Tool call(プレビュー・エージェントのみ)/ Tool response(プレビュー・エージェントのみ)/ Output
  • アクションは2つ: Annotate(モデルのみ)/ Annotate and block
  • 分類器は引き続き Azure AI Content Safety のモデルを利用
  • 既定ガードレールは Microsoft.DefaultV2(編集不可。テキスト・画像(視覚対応チャット / 画像生成)・音声モデルとも既定は Medium 閾値。 default-safety-policies の表。2026-10-14 更新: 旧 URL /azure/foundry/openai/concepts/default-safety-policies は 301 でこのページへ移動〈ms.date 2026-10-08。重大度の定義表も同ページに統合〉)
  • モデル向けガードレールは Azure が販売する全 Foundry Models に適用(音声文字起こしモデルの入出力を除く)。エージェント向けガードレールはプレビューで、Foundry Agent Service のエージェントのみ対象(Foundry Control Plane に登録した他のエージェントは対象外)。2026-10-14 更新: guardrails-overview(2026-10-09 再公開)は除外を「audio transcription models」、default-safety-policies(10-08 版)は「all models, except transcription models」と書き、音声モデル(Audio models)の既定ポリシー表(4 カテゴリ Medium+jailbreak+protected material text / code)を持つ。本書の旧記載「音声モデル除く」は文字起こしモデル(Whisper 等)に限る意味に読み替える(classic 版も以前から「excluding Azure OpenAI Whisper」+Audio Models 表。公開リポジトリが 404 のため旧版の文言との差分は確認できない)。2026-11-22 更新: guardrails-overview(ms.date 2026-11-02)は冒頭を「Agent guardrails for content safety in Foundry Agent Service are in preview」に改めた(egress の GA と区別するため。エージェント向けコンテンツセーフティのプレビュー扱いは不変)
  • エージェントに割り当てたガードレールは、基盤モデルのガードレールを完全に上書きする
  • REST API 上の実体は従来どおり RAI policy(ARM リソース)で、デプロイの raiPolicyName で割当て。リクエスト単位の上書きは x-policy-id ヘッダー
