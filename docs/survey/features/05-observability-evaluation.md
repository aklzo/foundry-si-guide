## 概要

- Tracing(Trace Replay 含む): **prompt / hosted / 外部(external)エージェントは GA、workflow エージェントのみプレビュー**(2026-11-22 更新。旧: 「GA for prompt and hosted agents; Preview for workflow and external agents」)

**4. サーフェス全般の傾向(2026-09-26 更新)**
観測性・評価領域の手順書は「Foundry(新)ポータル + Python SDK(`azure-ai-projects`)」が主線で、2026-08 の再編後は JavaScript/TypeScript(`@azure/ai-projects`)と REST(cURL)を全ページで併記。C#/.NET は 2026-09-07 時点では継続的評価ページのみだったが、2026-09-26 時点ではクラウド評価のハブと各 SDK ページ・トレース設定にも C# タブがある。REST の api-version は `2025-11-15-preview` が主だが、合成データ生成ページは `v1` を使用(混在)。**Azure CLI(`az`)の手順は Entra トレース取り込みのロール割当(`az role assignment create`)のみ**(2026-07-30 版の「どのページにも記載なし」から更新)。評価の CLI サーフェスは Azure CLI ではなく **azd 拡張(`azd ai agent eval`、プレビュー)** が担う。Insights は Foundry MCP Server / Microsoft Foundry Skill から読み取れる(2026-09-26 追記)。**(2026-11-22 追記)** azd の評価コマンドは `azure.ai.agents` 拡張の `azd ai agent eval` から、独立した `azure.ai.evaluations` 拡張の `azd ai eval`(azd 1.33.0 以上)に移った(azd 行。クイックスタートは旧コマンドのまま)。Azure CLI の出番は決定モデル judge のデプロイ(`az cognitiveservices account deployment create`)とロール付与。新ページ群(継続 / スケジュール評価・外部エージェント登録・音声評価)は Python / C# / JavaScript をそろえて併記、HITL・safety / task-level rubric は Python とポータルが中心。ローカル実行は `azure-ai-evaluation`(決定モデル judge)、Agent Framework からは `FoundryEvals` でも呼べる。

**7. Ignite 2026(2026-11-17〜)の「継続改善ループ」と各機能のステータス(2026-11-22 追記)**
Azure ブログ「Continuous improvement comes to Microsoft Foundry」(2026-11-17、 https://azure.microsoft.com/en-us/blog/continuous-improvement-comes-to-microsoft-foundry/ )・Book of News( https://news.microsoft.com/events/ignite/2026/book-of-news/ )・devblogs「What's new in Foundry Agent Service at Ignite 2026」(2026-11-18、 https://devblogs.microsoft.com/foundry/whats-new-in-foundry-agent-service-at-ignite-2026/ )は、観測・評価をループの 4 段階として打ち出した。本書のステータス(GA 一覧表を正、なければ Learn → ブログの順)との対応:
- **Establish(良さの基準を決める)**: 品質ルーブリック = GA(Learn 明記)/ safety rubric・task-level rubric = プレビュー / トレース注釈(Human in the loop)・注釈からの評価データセット・golden dataset = プレビュー / multi-turn evaluation = BoN は GA、Learn はページにより preview(併記)
- **Identify(問題を見つける)**: Insights = GA(GA 一覧表に行なし)/ 外部エージェント(LangGraph・LangChain〈・CrewAI はブログのみ〉)の登録とトレース = GA / クラスター分析 = プレビュー
- **Optimize(改善案を試す)**: Agent optimizer = GA 一覧表 Limited preview(BoN は GA)、insights → optimizer・skill optimization・cost optimization = プレビュー(03-agent-service)
- **Validate and repeat(改善を証明する)**: 継続評価・スケジュール評価・Agent Monitoring Dashboard = Learn はラベルなし・GA 一覧表 Monitoring = Preview(本書はプレビュー扱い)/ 定期 red teaming・評価アラート = プレビュー / GitHub Actions・azd の評価ゲート = プレビュー / 版比較の統計検定は GitHub Action の機能として記載
- **judge の選択肢**: 決定モデル judge(Microsoft-Decision-1)= プレビュー。**Learn は Decision-1.1 を judge 非対応と明記**(Azure ブログ・TC の「1.1 も judge に使える」と食い違い)、Decision-1 は **2027-02-04 にリタイア**予定 / 音声評価器 = 音声エージェントの監視・評価としてプレビュー

設計上の含意: (1) 本番ゲートの合否判定を GA の部品(Tracing・Insights・品質ルーブリック・組み込み評価器・red teaming)で組み、HITL・safety rubric・決定モデル judge はプレビューとして並走させる。(2) 外部エージェントは「観測と評価だけを Foundry に寄せる」選択肢が GA になった一方、イベント起動の継続評価・人手評価・red teaming は対象外なので、スケジュール型トレース評価で代替する。(3) Control Plane の custom agents(AI Gateway 経由)は 2027-05-07 に廃止されるため、既存の非 Foundry エージェント監視は外部エージェント登録へ移す計画を立てる。
