## 概要

Foundry Agent Service は Responses API を単一エントリポイントとするエージェント構築・実行のマネージドプラットフォーム。**サービス本体は GA**(「Foundry Agent Service is generally available (GA). Some sub-features are in public preview.」)。ただし旧世代(Agents v1 / Assistants API)の廃止と、Memory・Skills・voice-based agents・egress controls 等の新プレビュー機能の追加が同時進行しており(Routines は 2026-09 に GA 化。2026-09-26 確認)、**「GA だが足元が動いている」状態**である点に注意。**2026-11-22 追記(Ignite 2026):** voice agents(Learn・SDK・ブログは GA / GA 一覧表は Preview)・long-running hosted agents・hosted の network egress controls が GA 側に移った一方、Microsoft Copilot harness・memory snapshots・private CA trust・Azure Policy による egress 統制・session compute API・AgentBlueprint 認可などの新しいプレビューが加わり、状態は変わっていない。エージェントの作り方は prompt(既定ランタイム / Copilot harness を作成時に選択)・voice-based prompt・hosted の 3 種別と、エージェントを保存せず Responses API を直接呼ぶ ephemeral の計 4 通り(overview ms.date 2026-10-26・concepts/prompt-agents ms.date 2026-11-04)。

**用語マッピング(v1 → v2)**(出典: https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/migrate ):

| 旧(v1 / Assistants) | 新(v2) | 補足 |
|---|---|---|
| Threads | Conversations | メッセージだけでなく item のストリームを格納 |
| Messages | Conversation Items | `conversations.items.create()` が `messages.create()` を置換 |
| Runs | Responses | 入力 item→出力 item。ツールコールループは明示管理 |
| Assistants | Agents(Agent Versions) | エージェント定義は `create_version()`。自動バージョンスナップショット |

**1. v1→v2 移行の実務ポイント**
移行ツール( https://aka.ms/agent/migrate/tool )はコード構造を変換するが、**状態データ(過去の runs / threads / messages)は移行されない**(新 API 側で会話を作り直す)。新 API では会話/レスポンスは OpenAI クライアント(`project.get_openai_client()`)、エージェント作成・バージョン管理はプロジェクトクライアント、という**2クライアント構成**。旧 `create_agent()` は SDK v2.0.0 で削除済み。

**2. ツールの GA/プレビュー差(移行ガイドの対比より)**
新 Foundry では MCP=GA、Web Search=GA(リージョン依存。limits-quotas-regions 2026-09-07 版には Web Search の preview 表記なし)、**A2A=GA(`a2a_preview` はパブリックプレビュー。migrate 2026-09-11 版で更新)**、Image Generation=パブリックプレビュー。Work IQ は migrate の対比表(2026-09-11 版)には行がなく、limits のモデル別ツール表で「Work IQ (preview)」。**Azure Functions ツールと Deep Research ツールは新 Foundry の対比表上「なし」扱い**の記述があるが、ツールカタログ側の詳細は [04-tools-knowledge](./04-tools-knowledge.md) を参照(Deep Research は非推奨が確定、後継は `o3-deep-research` モデル+Web search)。**2026-11-22 追記(Ignite、devblogs 2026-11-18):** Web Search(Web IQ)は **prompt agent で GA、toolbox 経由は coming soon**、A2A ツールは GA、**computer use と browser automation は GA**(browser automation の閉域アプリ接続はプレビュー)、Work IQ / Fabric IQ 統合はプレビュー、toolbox のツールポリシーはプレビュー。ツール個別の確認は [04-tools-knowledge](./04-tools-knowledge.md)。

**4. 課金・クォータ概要**
- Prompt agents: 呼び出しごとの推論+ツール使用分(コンピュート課金なし)。
- Hosted agents: 上記+**セッションに割り当てた CPU / メモリ × compute の稼働時間**で課金(使用率ではなく割り当て量。セッション毎サンドボックス、アイドル既定 15 分〈**2〜240 分**で設定可。2026-11-22 に Learn へ反映され両論解消〉でスケールゼロ。**idle で止まるまでの待機時間も課金**され、`stop` で課金終了 — hosted-agents 2026-11-16 版)。同時セッション数はサブスクリプション×リージョン既定 2,000 / 1,000(**引き上げ可**。idle / 停止中のセッションは数えない)。memory snapshots(preview)は起動を速めるが課金体系の記載はない。
- Microsoft Copilot harness(preview): **2026-12-01 から**サンドボックスの CPU 0.0994 USD / vCPU 時・メモリ 0.0118 USD / GiB 時(devblogs 2026-10-28。それまではハーネス実行は無料、推論・ツールは別途課金)。
- Voice agents(2026-11 に Learn・SDK で GA。GA 一覧表は Preview): 音声トークン中心の別課金(`managed` はエージェント側、`self_deployed` は自前デプロイ側の課金。トレースの推定コスト属性は請求記録ではない — voice-agent-pricing 2026-10-06 版、2026-11-11 版でも同じ整理)。音声セッション最長 60 分、音声会話保持 60 日(limits-quotas-regions 2026-11-18 版で不変)。
- **会話データの保持(2026-11-22 追記、limits-quotas-regions 2026-11-18 版で新記載):** basic 構成は Microsoft 管理の Cosmos DB に conversations / items / responses を **60 日**保存して自動削除(期限切れの会話は 404)、standard 構成は自前 Cosmos DB の `run-state-v1` コンテナで既定 TTL 60 日(変更可)。削除後は復元不可 → 長期保存が要件なら自前で写しを持つか standard で TTL を延ばす。対象は会話データで、ファイル・vector store は別。
- **プロジェクトの接続数上限 120**、hosted agent の変換後イメージ上限(0.5 vCPU 3 GiB 〜 4 vCPU 以上 40 GiB)、新しい永続セッションボリューム最大 100 GiB も同版で明記(2026-11-22 追記)。
- サービス固定リミット(引き上げ不可。limits-quotas-regions 2026-09-07 版で再確認): ファイル 10,000/agent・thread、prompt agent のアップロード 512MB/ファイル・計 300GB、vector store 添付 2,000,000 トークン/ファイル、メッセージ 10 万/スレッド・本文 150 万文字/メッセージ、ツール 128/agent、**バージョン 1,000/agent**(旧記載「リビジョン」を公式表記に合わせ更新)。
- セットアップは basic(Microsoft 管理ストレージ)/ standard(BYO Cosmos DB・AI Search・Storage)の2種。
- 料金: https://azure.microsoft.com/pricing/details/foundry-agent-service/
