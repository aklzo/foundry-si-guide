## 概要

Foundry Agent Service は Responses API を単一エントリポイントとするエージェント構築・実行のマネージドプラットフォーム。**サービス本体は GA**(「Foundry Agent Service is generally available (GA). Some sub-features are in public preview.」)。ただし旧世代(Agents v1 / Assistants API)の廃止と、Memory・Skills・voice-based agents・egress controls 等の新プレビュー機能の追加が同時進行しており(Routines は 2026-09 に GA 化。2026-09-26 確認)、**「GA だが足元が動いている」状態**である点に注意。

**用語マッピング(v1 → v2)**(出典: https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/migrate ):

| 旧(v1 / Assistants) | 新(v2) | 補足 |
|---|---|---|
| Threads | Conversations | メッセージだけでなく item のストリームを格納 |
| Messages | Conversation Items | `conversations.items.create()` が `messages.create()` を置換 |
| Runs | Responses | 入力 item→出力 item。ツールコールループは明示管理 |
| Assistants | Agents(Agent Versions) | エージェント定義は `create_version()`。自動バージョンスナップショット |

## 補足ノート

**1. v1→v2 移行の実務ポイント**
移行ツール( https://aka.ms/agent/migrate/tool )はコード構造を変換するが、**状態データ(過去の runs / threads / messages)は移行されない**(新 API 側で会話を作り直す)。新 API では会話/レスポンスは OpenAI クライアント(`project.get_openai_client()`)、エージェント作成・バージョン管理はプロジェクトクライアント、という**2クライアント構成**。旧 `create_agent()` は SDK v2.0.0 で削除済み。

**2. ツールの GA/プレビュー差(移行ガイドの対比より)**
新 Foundry では MCP=GA、Web Search=GA(リージョン依存。limits-quotas-regions 2026-09-07 版には Web Search の preview 表記なし)、**A2A=GA(`a2a_preview` はパブリックプレビュー。migrate 2026-09-11 版で更新)**、Image Generation=パブリックプレビュー。Work IQ は migrate の対比表(2026-09-11 版)には行がなく、limits のモデル別ツール表で「Work IQ (preview)」。**Azure Functions ツールと Deep Research ツールは新 Foundry の対比表上「なし」扱い**の記述があるが、ツールカタログ側の詳細は [04-tools-knowledge](./04-tools-knowledge.md) を参照(Deep Research は非推奨が確定、後継は `o3-deep-research` モデル+Web search)。

**3. CLI サーフェスの注意**
`az cognitiveservices agent` は公式間で表記揺れ: Agent Service ドキュメントは削除済みとして azd を案内する一方、**Azure CLI リファレンスには Core・Preview として現存**(hosted agent の create/logs/start/stop 等。 https://learn.microsoft.com/en-us/cli/azure/cognitiveservices )。開発フローの主線は **azd**(`azd ai agent init/run/invoke` 等 — コマンド列挙もページ間で揺れあり)、管理操作は `az rest`。ほかに VS Code の Foundry Toolkit、コーディングエージェント用 `azure.ai.routine` の各サービス種別と `memoryStores` を宣言。azure-yaml-reference 2026-08-19 版)。拡張のインストールコマンドもページ間で揺れあり(`azd ext install microsoft.foundry` / `azd extension install azure.ai.agents` / `azd **4. 課金・クォータ概要**
- Prompt agents: 呼び出しごとの推論+ツール使用分(コンピュート課金なし)。
- Hosted agents: 上記+**アクティブセッション中の CPU/メモリ消費**で課金(セッション毎サンドボックス、アイドル既定 15 分〈2〜60 分で設定可。REST 仕様と azd は上限 240 分に拡大済みで Learn と両論 — 上表〉でスケールゼロ)。同時セッション数はサブスクリプション×リージョン既定 2,000 / 1,000(**引き上げ可**)。
- Voice-based agents(preview): 音声トークン中心の別課金(`managed` はエージェント側、`self_deployed` は自前デプロイ側の課金。トレースの推定コスト属性は請求記録ではない — voice-agent-pricing 2026-10-06 版)。音声セッション最長 60 分、音声会話保持 60 日(limits-quotas-regions 2026-10-14 再取得で不変)。
- サービス固定リミット(引き上げ不可。limits-quotas-regions 2026-09-07 版で再確認): ファイル 10,000/agent・thread、prompt agent のアップロード 512MB/ファイル・計 300GB、vector store 添付 2,000,000 トークン/ファイル、メッセージ 10 万/スレッド・本文 150 万文字/メッセージ、ツール 128/agent、**バージョン 1,000/agent**(旧記載「リビジョン」を公式表記に合わせ更新)。
- セットアップは basic(Microsoft 管理ストレージ)/ standard(BYO Cosmos DB・AI Search・Storage)の2種。
- 料金: https://azure.microsoft.com/pricing/details/foundry-agent-service/
